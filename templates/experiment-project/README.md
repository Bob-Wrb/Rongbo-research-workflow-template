# 实验处理计划示例

以下为可替换的设计示例。创建项目时按实际证据更新。

| 项目 | 示例与填写方法 |
| --- | --- |
| 原始数据 | 登记只读输入 ID、采集条件、单位与 SHA-256；私有原件存受控位置。 |
| 处理脚本 | 计划创建 scripts/process.py，读取输入、校验列名、输出独立结果表。 |
| 参数 | 示例指定窗口为 5 个采样点；登记实际参数与选择理由。 |
| 环境要求 | 记录 Python 版本、依赖锁和系统；仪器驱动留在 Local。 |
| 复现 | 保存运行命令和参数文件，使用同一合成输入在新目录重复运行。 |
| 验证 | 用常量序列检查平滑后内部点保持常量；明确边缘策略，核对行数和单位。 |
| 生成输出 | 分别登记处理表、图和日志，关联输入 ID、参数、脚本 SHA 与验证结果。 |
