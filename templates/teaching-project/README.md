# 课程制作计划示例

以下为可替换的设计示例。创建项目时按实际证据更新。

| 项目 | 示例与填写方法 |
| --- | --- |
| 课程目标 | 完成课后能解释单位错误，并用最小输入验证转换函数。 |
| 受众 | 面向有基础 Python 经验、首次处理仪器数据的研究生。 |
| 课堂结构 | 5 分钟诊断题，10 分钟演示，15 分钟结对练习，5 分钟反馈。 |
| 教学材料 | 准备合成数据表、演示脚本、练习单及教师答案；核对投影字号。 |
| 讲解脚本 | 展示标有 m 的列，先请学生预测换成 cm 的数值，再运行转换并解释差异。 |
| 考核材料 | 给出 1 m 和 0 m，要求提交转换结果、单位和验证步骤；按数值、单位和解释分别评分。 |
