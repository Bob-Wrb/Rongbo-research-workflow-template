# 执行结果独立复核

提供 TASK.md、基准与交付 SHA、PR 或脱敏 diff、输入版本、执行命令、输出摘要和未验证项。在 ChatGPT Project 粘贴：

```text
请对照 TASK.md 的原始验收项独立复核本次提交。先说明你实际读到的分支、差异和证据。
逐项列出预期、实际证据、通过/失败/证据不足。检查原始文件保护、单位、数据来源、
引用支持范围和复现步骤。区分你亲自核对的内容与执行者自述。
若无法读取 PR，请明确缺少的文件或差异。给出可定位的修改要求与复验方法。
最后列出可合并条件、责任人待定事项和应写入项目上下文的决定。
```

负责人把需改动项发回原任务分支。新提交须重跑受影响的验收项并传递新 SHA。
