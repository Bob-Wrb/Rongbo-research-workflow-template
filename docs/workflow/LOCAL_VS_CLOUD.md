# 执行环境选择

按表自上而下判断，在 TASK.md 写下所选环境、触发条件与验证方式。

| 可观察条件 | 选择 | 开始前检查 |
| --- | --- | --- |
| 输入受限、需仪器、内网服务或未提交文件 | Local | 在批准的位置验证只读访问和输入版本 |
| 需要本机 Word、字体或专用驱动 | Local | 用目标软件渲染一页或读取测试样本 |
| 依赖已锁定、输入已脱敏且能从仓库重建 | Cloud | 在独立环境安装依赖并运行最小样例 |
| 需要检查另一环境能否复现 | Cloud | 从指定 SHA 启动，比较输出容差 |
| 真实输入受限但算法可共享 | 两步执行 | Cloud 用合成输入验证逻辑，Local 用同一 SHA 验证真实数据，只回传允许共享的摘要 |

两个环境都合适时，短时交互调试优先 Local，可独立验收的并行任务可用不同分支在 Cloud 执行。
